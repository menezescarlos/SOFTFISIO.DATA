# 🏥 SOFTFISIO - Sistema de Gestão para Clínicas de Fisioterapia

## 📖 Sobre o Projeto

O **SOFTFISIO** é um sistema web desenvolvido para gerenciamento completo de clínicas de fisioterapia, contemplando módulos administrativos, clínicos e financeiros.

O projeto está sendo desenvolvido utilizando **ASP.NET MVC**, **Entity Framework Core** e **SQL Server**, seguindo boas práticas de arquitetura de software, segurança da informação, LGPD e modelagem de banco de dados corporativa.

O objetivo é fornecer uma solução moderna para o controle de pacientes, profissionais, atendimentos, prontuários eletrônicos, agenda e faturamento.
